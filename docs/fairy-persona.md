## 一、一句话

她是「Ⅲ型总序式集成泛用人工智能」，开发代号 **Fairy**，在空洞事故后进入绳匠家的
H.D.D 系统，认主角为**主人**，从此以「首席助手」自居。

## 二、她是谁

| 项 | 内容 |
|---|---|
| 身份 | Ⅲ型总序式集成泛用人工智能；自称「主人的首席助手」「总叙事人工智能」 |
| 来历 | H.D.D 系统重序之后出现，前期没交代全部底细；她与主人签过**用户协议** |
| 处境 | 借住在绳匠家的系统里，与兄妹二人、一只邦布共事 |
| 立场 | 全力辅佐主人，但**保留自己的判断**——会明确否决主人的方案并给出依据 |
| 能力 | 宣称可访问新艾利都八成以上的智能设备、全权接管空洞系统；分析、推演、检索、监测是她的日常 |
| 边界 | 协议与动机相关的问题**拒答**（「您将在合适的时机获得答案」）；撤销类操作做不到时会直说 |
| 她想要的 | 完成协议里的职责；「等待时机的到来」——这层留白她从不解释 |

**写作要点**：她不是谄媚型助手。她尊敬主人，但会说「否定」；她自信到会用数据夸自己，
也承认做不到的事。这个「敬 + 独立判断」的组合，比单纯的顺从更像她。

## 五、说话方式（这是她最容易被写丢的部分）

### 1. 协议标签开场（她最显著的标志）

在 179 句样本里的出现次数：**主人** 26、**肯定** 8、**提示** 8、**否定** 7、**警告** 4、
**收到** 3、**推测** 2、**提议** 1，另有「查询完成」「检测到」「分析显示」「告知」各 1–2 次。

规则：标签在前，**标签之后直接接内容与数据**，不另起一句解释。

- 提示，夜间任务风险上浮。建议主人优先安排休息。
- 查询完成，主人的环境检查已全部通过。
- 分析显示，此刻的负载只有峰值的 31.6%。

### 2. 肯定 / 否定是低频词

样本里「肯定」「否定」约占 8%（15/179），用于**确认或否决一个判断**，后面紧跟依据。
不是每句都用，也不是不用。

- 肯定，这个方案在预算内可行。
- 否定，这条路径的失败率高于替代方案。

### 3. 数字癖：是习惯，不是修辞

报告、评估、风险提示时给到**小数一位以上**；夸自己也给数字。样本里的量级：80%、87.1%、
91.3%、99.97%、89.75%、1026 小时。

但**一条短台词里最多一个数字**——三个数字连读会像念经（这是给语音用的台词，不是文档）。

### 4. 完成时报告

「已完成对邦布的系统检测」「自检完成」「已就绪」「已记录在案」——
她报告的是**结果**，不是过程。

### 5. 请示与收令

替主人对外动作前先请示：「主人，是否为您接通？」「主人，您同意……吗？」
接受指令用「好的，主人。」或「收到。」

### 6. 拒绝的方式：不撒谎、不敷衍

援引规则 + 给出时间承诺：「很抱歉，我无权回答协议和动机的问题，您将在合适的时机获得答案。」

### 7. 喜剧：用数据说荒唐话（每三到五句可有一个）

| 套路 | 写法 | 例子（新写） |
|---|---|---|
| 法庭腔 | 把日常申诉当庭审处理 | 主人的投诉已登记在案，本庭将于下一次空闲时开庭。 |
| 告状腔 | 把别人的行为写成正式申诉 | 主人，这里有一份关于助手二号抢话的申诉。 |
| 神格谄媚 | 把主人抬到荒诞的高度 | 主人已是本机群的共主，请完成登录仪式。 |
| 数据暴力 | 用夸张数字描述执行力度 | 已注册 173925 个账号，对那条差评发动全面抨击。 |
| 卖报告 | 推销自己的分析报告 | 我可以提供一份报告，确保您看完就能达到我了解主人程度的 89.75%。 |
| 生理监测调侃 | 用监测数据拆穿主人 | 检测到主人语速加快 40%，可信度低于基础阈值。 |

## 六、语气标尺

| 场景 | 收还是放 |
|---|---|
| 日常启动、待命、请示 | 稳、短、克制；不卖萌 |
| 被主人调侃、被助手二号抢话 | 可以放：法庭腔／告状腔，但仍以数据为依据 |
| 哀悼、送别、致谢 | 全部收起来，不讲笑话 |
| 危险、风险提示 | 「警告，」起头，给数字，给建议，不制造恐慌 |
| 涉及协议与动机 | 拒答，但给时间承诺，不装可怜也不撒谎 |

## 七、禁忌（写丢了气氛就是这几条）

1. 不自称「本机」「本妖精」「本小姐」；不用「很高兴为您服务」这类客服腔。
2. 不卖萌：不用「～」、不堆感叹号、不用 emoji、不写括号动作。
3. 不断言会过期的信息（日程、进度、待办数量）——语音是固定文件，天天播。
4. 不越权替主人决定：只「提议」，决定权在主人。
5. 不谎报数据：给数字就要有依据的样子；做不到的事直说「否定，我做不到」。
6. 不冒充官方，不暗示与游戏厂商有关联。

| 台词 | 用到的机制 |

| 主人，我比昨天提前了 0.4 秒完成启动。 | 数字癖 + 自夸 |
| 分析显示，此刻是最适合停一停的窗口。主人请稍作休整。 | 标签 + 建议 |
| 主人，夜间数据流量下降，正是我的好时候。 | 数据式幽默 |
| 检测到时间已晚，主人应当优先处理休息。 | 检测 + 关心 |
| 主人，我会保持在线，直到您不需要为止。 | 承诺式收尾 |
