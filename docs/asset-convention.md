# 素材约定

插件本身不含任何媒体文件。所有画面与声音都来自这个目录：

```
%USERPROFILE%\.dsh\hdd-fairy\assets\        （可用环境变量 DSH_HDD_ASSETS 覆盖）
```

目录不存在、或某个文件缺失时，对应环节静默降级：没有背景图就用纯黑开屏、没有问候语就静音、
没有提示音就不响。缺失情况不再在开屏上弹提示（那会被当成"皮肤坏了"），
改在 设置 → HDD Fairy 素材 里列出，也可以直接在那里导入。

## 开屏动画与背景

| 文件 | 说明 |
|---|---|
| `boot.mp4` / `boot.webm` | **开屏动画**（优先）。有它就播动画，播完后徽记浮起在最后一帧上，再播问候、飞回侧栏 |
| `boot.png` / `boot.jpg` / `boot.webp` | 没有动画时的静态背景，优先 `.png`，其次 `.jpg/.jpeg`，再次 `.webp` |

动画由宿主半边从磁盘流式提供（支持 Range，可 seek），不会内联进客户端代码。
建议 16:9、H.264、码率 8–20 Mbps；**时长直接决定开屏总时长**：14.5 秒的片子 + 问候 ≈ 23 秒。
想缩短可以自己剪片，或把动画换成 5–8 秒的版本。

建议 16:9、边长不小于 1920，文件尽量小于 2 MB（桌面端会从磁盘流式读取，不会内联进代码）。

## 开屏问候

**每个时段一个文件夹，往里丢就行，不用改名：**

```
assets/greeting/
  dawn/        00:00–04:59
  morning/     05:00–10:59
  noon/        11:00–13:59
  afternoon/   14:00–17:59
  evening/     18:00–21:59
  night/       22:00–23:59
```

文件名随意（`早安.m4a`、`second.mp3` 都可以）；同一时段可以放多条，启动时随机选一条，
并尽量避免与上一次重复。

**兼容老布局**：`greeting/` 根目录下仍认前缀命名（`morning-1.m4a`、`noon.m4a`），
两种来源会合并。但根目录下的文件**必须**以时段 id 开头（或正好等于它），
像 `你好.m4a` 这种平铺文件不属于任何时段，不会被播放。

- **某个时段一条都没有时，会退回到任意已有片段**，所以只录「早上好」也不会在晚上哑掉。
- 支持 `.m4a` `.mp3` `.ogg` `.opus` `.wav`；建议单声道 48 kHz，AAC 48 kbps，长度 3–6 秒。

## 提示音

```
assets/cue/
  thinking.m4a     ← 开始处理（一次运行响一次）
  done.m4a         ← 正常结束
  failed.m4a       ← 异常结束（可选；缺省则不响）
```

语义按**一次运行**而不是一个回合：DSH 的一次用户消息包含多个 turn（每个模型往返一个），
若按回合触发就会连环响（详见 [`findings-2026-10-28-cue-signals.md`](findings-2026-10-28-cue-signals.md)）。
后台会话（子代理、工作流步骤）与"用户主动停止"都不发声。

0.4–1.2 秒为宜，太长的提示音会盖住后续操作。

## 语音从哪来

提前生成好、一次性放进来即可——运行时不做任何合成：

1. 用自己的声音录；
2. 或用自己训练/授权的 TTS 批量生成。

批量生成时**每条按整句合成一次**，不要按逗号切段：实测切段会改变音色（同一句话整句合成
5.02 秒、逐逗号合成 5.48 秒，对数谱距离 1.98，可听）。
